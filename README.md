# SpellInfo

A small site to display info about a gift that someone has recieved

## Features
- See the ingredients/items used 
- Can see more info about each item

## Tech Stack
- React
- JavaScript (ES6+)
- CSS

## How to Run Locally
1. Clone the repo
2. Install dependencies:
   npm install
3. Start the app:
   npm run dev
4. Open http://localhost:5173/
